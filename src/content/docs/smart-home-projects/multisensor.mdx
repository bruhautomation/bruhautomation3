All-in-one room sensor combining temperature, humidity, motion detection, ambient light measurement, and an RGB status LED. Perfect for automations that need to know what's happening in a room.

## How It Works

The multisensor monitors your environment on a NodeMCU v2 (ESP8266) and exposes all readings to Home Assistant. The DHT22 tracks temperature and humidity, a photoresistor measures ambient light, and a PIR sensor detects motion. An addressable RGB LED provides visual feedback—control its color and apply effects like flicker, strobe, or random animations.

## Hardware

- **Board:** NodeMCU v2 (ESP8266)
- **Temperature/Humidity:** DHT22 sensor (D7)
- **Motion Detection:** PIR sensor (D5)
- **Light Level:** Photoresistor on analog input (A0)
- **Status LED:** RGB LED with PWM control (D1 red, D2 green, D3 blue)

## Firmware

This project runs [ESPHome](https://esphome.io/). The full configuration is available on [GitHub](https://github.com/bruhautomation/BRUH-CAD-Files/tree/main/smart-home/multisensor).
