Wall-mounted touchscreen dashboard using Nextion HMI displays (3.5" and 5" variants) with custom scenes, ESP32 integration, and Home Assistant connectivity. Control your smart home and see real-time status from a beautiful, responsive interface.

## How It Works

A Nextion display connects to an ESP32 via UART, receiving live data from Home Assistant. The HMI (Human Machine Interface) files define custom touchscreen layouts with buttons, sliders, and data displays. Tap a button to trigger scenes, adjust brightness, or control devices. All communication stays local between Home Assistant and ESP32.

## Hardware

- **Display:** 3.5" or 5" Nextion touchscreen (UART serial interface)
- **Microcontroller:** ESP32 (NodeMCU-32S)
- **Power:** 5V USB or external supply
- **Data:** UART on GPIO16 (RX) and GPIO17 (TX) at 9600 baud
- **Enclosure:** 3D-printed mounting brackets for wall installation

## Firmware

This project runs [ESPHome](https://esphome.io/). The full configuration is available on [GitHub](https://github.com/bruhautomation/BRUH-CAD-Files/tree/main/smart-home/nextion-touch-panel).
