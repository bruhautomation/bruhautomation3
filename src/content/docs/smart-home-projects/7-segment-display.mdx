Wall-mounted 8-digit 7-segment display driven by MAX7219. Display real-time data from Home Assistant—subscriber counts, sensor readings, temperatures, or any numeric value you want to see at a glance.

## How It Works

The MAX7219 handles the multiplexing of the 7-segment display digits via SPI. An ESP32 fetches data from Home Assistant (like YouTube subscriber count or temperature) and updates the display using ESPHome's lambda display function. Brightness is adjustable in 16 steps.

## Hardware

- **Board:** ESP32 (NodeMCU-32S)
- **Display Driver:** MAX7219 (SPI interface)
- **Display:** 8-digit 7-segment common cathode
- **SPI Pins:** CLK (GPIO21), MOSI/Data (GPIO22), CS (GPIO23)

## Firmware

This project runs [ESPHome](https://esphome.io/). The full configuration is available on [GitHub](https://github.com/bruhautomation/BRUH-CAD-Files/tree/main/smart-home/7-segment-display).
