A compact, motorized mixer designed to agitate 50mL conical culture tubes. Adjustable speed makes it suitable for both gentle suspension of settled cells and vigorous mixing of media and reagents.

## Design

A NEMA 17 stepper motor drives an orbital mixing platform. The 3D-printed frame holds a single or dual tube configuration at an optimal angle for uniform mixing. Variable speed firmware allows fine-tuning for different cell types and media viscosities.

## Hardware

- **Motor:** NEMA 17 stepper (adjustable torque)
- **Driver:** A4988 stepper driver with microstepping
- **Controller:** Arduino or ESP32
- **Platform:** 3D-printed orbital mixing head
- **Base:** Printed PETG for rigidity and bench durability

## Features

- **Adjustable speed:** 0-500 RPM range via software
- **Compact:** Fits standard lab bench with other equipment
- **Quiet:** Stepper motor operation is subdued
- **Durable:** PETG frame handles repeated use and occasional spills
- **Simple assembly:** Metric fasteners and modular design
