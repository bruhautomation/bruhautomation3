A custom-built controller for Cellcube bioreactors, replacing manual media exchange with fully automated process control. Features a Nextion touchscreen display, NEMA 23 stepper motor driving a precision gear system, and a complete fluidics panel with pinch valves for media dosing and sampling.

## Design

The controller automates critical bioreactor maintenance tasks — media feeding, pH adjustment, temperature control, and sample collection — all coordinated through a custom firmware stack. The system monitors real-time metrics on an intuitive touchscreen interface and logs data for retrospective analysis.

The gear-driven pump system ensures accurate, repeatable fluid transfers. The fluidics panel organizes peristaltic pump lines, check valves, and sterile filters into a compact manifold accessible from outside the incubator.

## Hardware

- **Controller:** ESP32 with WiFi connectivity
- **Display:** Nextion 5-inch HMI touchscreen
- **Motor:** NEMA 23 stepper (precise positioning)
- **Drive:** Microstepping driver with step/direction control
- **Pump:** Gear-driven peristaltic system (±2% accuracy)
- **Valves:** Three-position pinch valve solenoids
- **Sensors:** Temperature, pH, dissolved oxygen (integrated)
- **Frame:** Aluminum extrusion with custom 3D-printed gear components

## Features

- **Automated feeding:** Programmable media exchange intervals
- **Real-time display:** Live parameter monitoring and alerts
- **Data logging:** SD card storage for compliance and analysis
- **Modular fluidics:** Swappable valve configurations
- **Integration:** MQTT/Home Assistant control
- **Sterilization-safe:** Quick-disconnect sterile connectors
