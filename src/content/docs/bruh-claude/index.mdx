## What it is

A Home Assistant add-on that runs **Claude Code** inside HA, with native access to your entities, services, automations, traces, history, cameras, and logs through a built-in MCP server. Open a terminal in your sidebar, talk to it through Voice Assistants, schedule it to watch your house, or call it from automations. Either way, Claude actually knows your setup.

![BRUH Terminal architecture overview](/images/bruh-claude/architecture-overview.svg)

  </Card>

    `bruh_claude.run_task` runs Claude in the background — error-log digests, config audits, morning summaries — with an optional done-notification.

    Live state and real history: *"How cold did it get last night?"*, *"Which automations haven't run in 30 days?"*

## Built for Home Assistant

What makes this different from running Claude Code on a regular machine:

- **Your Claude subscription covers it** — OAuth sign-in, so Pro/Max includes your usage; an API key works too.
- **[34 purpose-built MCP tools](/bruh-claude/mcp/)** — live states, device control, cameras, history and statistics, registries, traces, templates, logs, reloads.
- **Auto-generated context** — every boot regenerates `/config/CLAUDE.md`, a snapshot of your install that Claude reads at the start of each session.
- **Usage-limit sensors** — the same session/weekly utilization as claude.ai → Settings → Usage, as HA sensors with reset times.
- **Safe by default** — voice agents get HA tools but no shell, file, or web access; per-agent blocked-services lists; non-root sandbox.
- **Git-based config backup** — auto-commits of `/config`, manual `ha-backup`, single-file restore from any commit.

**[Quick Start →](/bruh-claude/quickstart/)** — add the repo, install, restart HA once, sign in. About five minutes.
