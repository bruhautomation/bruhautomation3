## What it is

A Home Assistant add-on that runs **Claude Code** inside HA — with native access to your entities, services, automations, traces, and logs. Open a terminal in your sidebar, ask a question, and Claude actually knows your setup.

![BRUH Claude terminal session](/images/bruh-claude/terminal-hero.png)

## What you can do

<CardGrid>
  <Card title="Voice + text assistant" icon="comment-alt">
    Pick **BRUH Claude** as your conversation agent in **Settings → Voice Assistants**. Ask via the HA app, a smart speaker, or a wall tablet — voice or text. Claude responds with real data, not canned phrases.
  </Card>
  <Card title="Trigger from automations" icon="rocket">
    The `bruh_claude.run_task` service runs Claude in the background with an optional notification when done. Morning briefings, error-log digests, config audits — all hands-free.
  </Card>
  <Card title="Debug your automations" icon="error">
    Claude reads automation traces, cross-references entity state, and tells you *exactly* why something fired — or didn't. No more grepping `home-assistant.log`.
  </Card>
  <Card title="Just… ask anything" icon="information">
    *"Which automations haven't run in 30 days?"* *"What's my biggest energy draw right now?"* *"Render this template."* Live state, real answers.
  </Card>
</CardGrid>

## A taste

```
> Why didn't my morning routine run today?

automation.morning_routine last ran yesterday at 7:00 AM.
Looking at today's trace: the trigger fired at 7:00 AM but the
condition "binary_sensor.workday" evaluated to false — today is
Saturday.

Want me to update the condition so it runs on weekends too?
```

```
> Show me automations that haven't triggered in 30 days

Found 4:
1. automation.guest_room_welcome_lights — 47 days ago
2. automation.garage_door_reminder       — 62 days ago
3. automation.holiday_lights_schedule    — 91 days ago
4. automation.old_motion_sensor_test     — never

Want me to disable the unused ones?
```

## Built for Home Assistant

What makes this different from running Claude Code on a regular machine:

<CardGrid>
  <Card title="Use your Claude subscription" icon="approve-check">
    Authenticates with Anthropic via **OAuth** — so a Claude **Pro** or **Max** subscription covers your usage. No API key, no pay-per-token billing for everyday use.
  </Card>
  <Card title="Live HA awareness (MCP server)" icon="puzzle">
    A built-in MCP server gives Claude **14 purpose-built tools** — entity states, service calls, automation traces, templates, logs, config reload. No manual API setup.
  </Card>
  <Card title="Auto-generated context" icon="information">
    On every boot, the add-on regenerates `/config/CLAUDE.md` — a snapshot of your entities by domain, automation list with last-triggered times, installed integrations, and your file tree. Claude reads it at the start of every session.
  </Card>
  <Card title="Token usage as HA sensors" icon="seti:graphql">
    Real values from the Anthropic API — not estimates. 7 sensors (session, today, weekly, all-time, weekly session count) with reset timestamps. Build dashboards, set budget alerts.
  </Card>
  <Card title="Git-based config backup" icon="document">
    Auto-commit `/config` every 30 minutes (configurable). `ha-backup` for manual snapshots. Single-file restore from any commit. Sensible `.gitignore` excludes secrets.
  </Card>
  <Card title="CLI shortcuts" icon="seti:powershell">
    `ha-reload automations`, `ha-log core -f`, `ha-backup history`, `ha-context-gen`, `persist-install pip pandas` — the operations you'd otherwise SSH for, in your sidebar.
  </Card>
</CardGrid>

## Token usage sensors

Track real API spend in HA without scraping a dashboard.

| Sensor | What it tracks |
|--------|----------------|
| `sensor.bruh_claude_session_total_tokens` | Current Claude session |
| `sensor.bruh_claude_today_total_tokens` | Today (resets at midnight) |
| `sensor.bruh_claude_weekly_total_tokens` | This week (Mon–Sun) |
| `sensor.bruh_claude_weekly_sessions` | Distinct sessions this week |
| `sensor.bruh_claude_all_time_total_tokens` | Lifetime |

Plus session input/output split sensors and reset-time attributes. Updated every 30 seconds.

## Up and running in 5 minutes

1. Add the **BRUH HA Apps** repository in HA.
2. Install **BRUH Claude Terminal**.
3. Restart Home Assistant once.
4. Authenticate with Anthropic in the terminal.
5. Open the **BRUH Claude** sidebar entry and start typing.
