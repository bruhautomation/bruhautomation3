## What it is

A Home Assistant add-on that runs **Claude Code** inside HA, with built-in access to your entities, services, automations, and logs. Open a terminal in your sidebar, ask a question, and Claude actually knows your setup.

![BRUH Claude terminal session](/images/bruh-claude/terminal-hero.png)

## What you can do

<CardGrid>
  <Card title="Ask anything about your house" icon="comment-alt">
    *"Which automations haven't run in 30 days?"* *"Why didn't the morning routine fire today?"* — Claude queries live state, traces, and logs to give a real answer.
  </Card>
  <Card title="Control devices in plain English" icon="rocket">
    *"Turn off all the downstairs lights."* *"Set the bedroom to 68°."* Works as an Assist conversation agent for voice and text.
  </Card>
  <Card title="Debug automations" icon="error">
    Claude reads automation traces, cross-references entity state, and tells you exactly why something fired — or didn't.
  </Card>
  <Card title="Run tasks on a schedule" icon="setting">
    Trigger Claude from any HA automation. Morning briefings, error log digests, config audits — all hands-free.
  </Card>
  <Card title="Auto-versioned config" icon="document">
    Git-based snapshots of `/config` every 30 minutes. One-click restore on any file.
  </Card>
  <Card title="Token usage in HA" icon="approve-check">
    Real Anthropic API token counts as HA sensors. Build dashboards. Set alerts.
  </Card>
</CardGrid>

## A taste

```
> Why didn't my morning routine run today?

automation.morning_routine last ran yesterday at 7:00 AM.
Looking at today's trace: the trigger fired at 7:00 AM but the
condition "binary_sensor.workday" evaluated to false — today is
Saturday.

Want me to update the condition so it runs on weekends too?
```

```
> Show me automations that haven't triggered in 30 days

Found 4:
1. automation.guest_room_welcome_lights — 47 days ago
2. automation.garage_door_reminder       — 62 days ago
3. automation.holiday_lights_schedule    — 91 days ago
4. automation.old_motion_sensor_test     — never

Want me to disable the unused ones?
```

## Up and running in 5 minutes

1. Add the **BRUH HA Apps** repository in HA.
2. Install **BRUH Claude Terminal**.
3. Restart Home Assistant once.
4. Authenticate with Anthropic in the terminal.
5. Open the **BRUH Claude** sidebar entry and start typing.
