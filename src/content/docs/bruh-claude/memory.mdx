BRUH Claude keeps a small, human-readable long-term memory about your home at `/config/.bruh_claude/memory/` — preferences, entity nicknames, household patterns, device quirks. It's what turns *"turn on the beacon"* into the office lamp, and it's shared across every Claude surface in your house.

## What lives where

| File | What it is |
|------|------------|
| `memory.md` | The canonical knowledge file. **Plain markdown, user-editable**, capped at `memory_max_kb` (default 8 KB). |
| `voice.md` | A ≤2 KB distillate — the part spliced into every voice prompt. |
| `inbox/` | Append-only candidate facts (JSONL) waiting to be consolidated. |
| `questions.jsonl` | Open questions Claude wants answered, plus their answers. |

## How it learns

- **You tell it** — say *"remember that…"* to a voice assistant, run `ha-memory add "…"` in the terminal, or call `bruh_claude.add_memory` from an automation.
- **It notices** — when a voice conversation ends, a bounded reflection pass (cheap Haiku, no tools, ~60 s budget) extracts up to 3 durable facts: preferences, corrections, nicknames. Transient states, one-off commands, and secrets are excluded.
- **Other add-ons contribute** — [BRUH Insights](/bruh-insights/) hands over its findings and answered questions via `bruh_claude.add_memory` / `bruh_claude.answer_question`; add-ons without the integration drop facts into `/share/bruh_claude/memory-inbox/`. See [better together](/bruh-claude/better-together/).

A background **consolidator** merges the inbox into `memory.md` + `voice.md` once a day (or early when 20+ facts are pending) — deduping, resolving contradictions newest-wins, enforcing the size cap. Questions unanswered for 21 days retire automatically.

Learned knowledge is used in three places: **voice prompts** (`voice.md`), **insight jobs** (alongside each job's previous report for continuity), and the generated `/config/CLAUDE.md` **terminal context**.

## Viewing, editing, clearing

```bash
ha-memory list                        # what Claude knows
ha-memory inbox                       # facts awaiting consolidation
ha-memory add "Guests use the loft"   # queue a fact yourself
ha-memory questions                   # open questions Claude has
ha-memory answer "<question>" "<answer>"
ha-memory consolidate                 # run a consolidation pass now
ha-memory edit                        # open memory.md in $EDITOR
ha-memory clear --confirm             # reset (old file kept as memory.md.bak)
```

`memory.md` is yours to edit — your edits are the canonical content the consolidator merges into. (If you run BRUH Insights, its 🧠 Memory dialog edits the very same file.)

## Services

```yaml
# Queue a fact from an automation
service: bruh_claude.add_memory
data:
  fact: "The dog gets fed at 7 and 17 — kitchen lights on then means feeding time"
  confidence: high     # high | medium | low (default medium)

# Answer an open memory question
service: bruh_claude.answer_question
data:
  question: "Which thermostat schedule applies on holidays?"
  answer: "Treat holidays like weekends"
```

## Kill switches

- `assist_learning: false` — stop learning (no reflection, no consolidator).
- `memory_injection: false` — stop using memory in voice prompts.
- `ha-memory clear --confirm` — forget everything learned so far.
