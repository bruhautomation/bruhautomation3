The entity registry is where friendly names, entity ids, and visibility live. These services let Claude fix the `light.shelly_1pm_9a4c2f` mess at scale: rename in bulk, assign sane entity ids, disable noisy diagnostics, hide what dashboards shouldn't show, and sweep out registry entries whose integration is long gone.

:::caution
`change_entity_id` does **not** rewrite automations, scripts, or dashboards that reference the old id. Run [`find_orphaned_references`](/bruh-claude/power-tools/diagnostics-and-repairs/) afterwards to catch anything left pointing at the old name — Claude does this automatically when you ask it to rename things.
:::

## Rename entity

`bruh_claude.rename_entity`

Set the friendly name override of one or more entities.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `entity_id` | entity (list) | yes | Entities to rename. |
| `name` | text | yes | The new friendly name. |

```yaml
service: bruh_claude.rename_entity
data:
  entity_id:
    - light.shelly_1pm_abc123
  name: Kitchen Ceiling
```

> 🗣️ *"Rename light.shelly_1pm_abc123 to 'Kitchen Ceiling'."*

## Change entity ID

`bruh_claude.change_entity_id`

Change an entity's ID (e.g. light.shelly_abc123 to light.kitchen_ceiling). Automations and dashboards referencing the old ID must be updated separately.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `entity_id` | entity | yes | The current entity ID. |
| `new_entity_id` | text | yes | The new entity ID, same domain. |

```yaml
service: bruh_claude.change_entity_id
data:
  entity_id: light.shelly_1pm_abc123
  new_entity_id: light.kitchen_ceiling
```

> 🗣️ *"Give that Shelly a sane entity id: light.kitchen_ceiling."*

## Enable entity

`bruh_claude.enable_entity`

Enable one or more disabled entities. Takes effect after the owning integration reloads.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `entity_id` | entity (list) | yes | Entities to enable. |

```yaml
service: bruh_claude.enable_entity
data:
  entity_id:
    - sensor.zigbee_router_lqi
```

> 🗣️ *"Re-enable the LQI diagnostic sensor."*

## Disable entity

`bruh_claude.disable_entity`

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `entity_id` | entity (list) | yes | Entities to disable. |

```yaml

  entity_id:
    - sensor.noisy_diagnostic
```

> 🗣️ *"Disable that diagnostic sensor that spams the recorder."*

|-------|------|----------|-------------|
| `entity_id` | entity (list) | yes | Entities to hide. |

> 🗣️ *"Hide the child-lock switch from dashboards but keep it working."*

## Delete orphaned entities

`bruh_claude.delete_orphaned_entities`

Remove registry entries for entities whose integration no longer provides them (state shows as 'restored'). Runs as a dry run by default and returns the list of affected entities as response data.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `dry_run` | boolean | no | When on (default), only report what would be removed. |

```yaml
# Report only — nothing is deleted
service: bruh_claude.delete_orphaned_entities
response_variable: orphans

# The real thing, once you've reviewed the list
service: bruh_claude.delete_orphaned_entities
data:
  dry_run: false
```

> 🗣️ *"Are there any dead entities left over from integrations I removed? Clean them up."*
