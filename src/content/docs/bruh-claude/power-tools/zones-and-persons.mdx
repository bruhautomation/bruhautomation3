Location plumbing: zones define the places your automations care about, and persons tie the humans of the house to the devices that reveal where they are. Both are normally UI-only — these services open them to Claude and automations.

The `zone.home` zone set in `configuration.yaml` isn't editable — that's a Home Assistant rule, and these services respect it.

## Create zone

**`bruh_claude.create_zone`** — Create a new zone for location tracking.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | text | **yes** | Name of the new zone. |
| `latitude` | number | **yes** | Latitude of the zone center. |
| `longitude` | number | **yes** | Longitude of the zone center. |
| `radius` | number | no | Radius of the zone in meters (default 100). |
| `icon` | icon | no | Icon for the zone. |
| `passive` | boolean | no | Passive zones are only used for automations, not shown on the map. |

```yaml
service: bruh_claude.create_zone
data:
  name: Gym
  latitude: 52.3702
  longitude: 4.8952
  radius: 150
  icon: mdi:dumbbell
```

> 🗣️ *"Create a zone for the gym so automations know when I'm there."* — works in the terminal, by voice, or in an automation prompt.

## Delete zone

**`bruh_claude.delete_zone`** — Delete one or more UI-created zones.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `entity_id` | entity (list) | **yes** | Zone entities to delete. |

```yaml
service: bruh_claude.delete_zone
data:
  entity_id:
    - zone.gym
```

> 🗣️ *"Delete the gym zone."* — works in the terminal, by voice, or in an automation prompt.

## Add device tracker to person

**`bruh_claude.add_device_tracker_to_person`** — Attach one or more device trackers to a person for presence detection.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `entity_id` | entity | **yes** | The person entity. |
| `device_tracker` | entity (list) | **yes** | Device trackers to attach. |

```yaml
service: bruh_claude.add_device_tracker_to_person
data:
  entity_id: person.alex
  device_tracker:
    - device_tracker.alex_phone
```

> 🗣️ *"Track Alex with their new phone."* — works in the terminal, by voice, or in an automation prompt.

## Remove device tracker from person

**`bruh_claude.remove_device_tracker_from_person`** — Detach one or more device trackers from a person.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `entity_id` | entity | **yes** | The person entity. |
| `device_tracker` | entity (list) | **yes** | Device trackers to detach. |

```yaml
service: bruh_claude.remove_device_tracker_from_person
data:
  entity_id: person.alex
  device_tracker:
    - device_tracker.old_phone
```

> 🗣️ *"Stop tracking Alex's old phone."* — works in the terminal, by voice, or in an automation prompt.
