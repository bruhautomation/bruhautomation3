[BRUH Terminal](/bruh-claude/) and [BRUH Insights](/bruh-insights/) each work alone. Installed together they share one login and one memory: the Terminal acts, Insights analyzes.

## Setup

1. Install both add-ons from the [BRUH HA Apps repository](https://github.com/bruhautomation/BRUH-HA-Apps).
2. In the Terminal: sign in to Claude, then run `ha-share-login`.
3. Open Insights — it's already authenticated. Generate your first insight.
4. Say *"remember that…"* to your voice assistant; it appears in Insights' Memory dialog (🧠).

## Which one does what?

| | **BRUH Terminal** | **BRUH Insights** |
|---|---|---|
| **Claude acts as…** | Your operator: voice assistant, terminal, automation engine | Your analyst: scheduled reports with interactive visualizations |
| **Interface** | Sidebar terminal, Voice Assistants, services | Sidebar Ingress panel + dashboard cards |
| **Output** | Actions, answers, config changes | Insight cards: title, summary, highlight stats, charts |
| **Typical ask** | *"Turn off the kitchen lights"*, *"why didn't my automation fire?"* | *"Which rooms are coldest at night?"*, energy trends, device health |

## One login

Run `ha-share-login` once in the Terminal and your Claude subscription is shared<Detail inline min={2}> at `/config/.bruh_claude/secrets/`</Detail>. Insights picks it up automatically and shows "Claude · shared login" in its auth chip — no second sign-in, no pasted tokens. Revoke any time with `ha-share-login --revoke`.

## One memory

Both add-ons read and write the same home memory file, `/config/.bruh_claude/memory/memory.md`:

- Tell the Terminal *"remember that guests use the loft"*<Detail inline min={2}> (voice, `ha-memory add`, or `bruh_claude.add_memory`)</Detail> and Insights folds that fact into every future analysis.
- When Insights' analyst discovers a finding or you answer one of its questions, the knowledge lands in the shared memory. Voice answers get smarter because a report learned something.
- The Memory dialog in Insights and `ha-memory edit` in the Terminal are two editors for the same document.

<Detail min={3}>

A background consolidator dedupes and resolves contradictions newest-wins. Without the Terminal installed, Insights parks facts in `/share/bruh_claude/memory-inbox/` drop-files, ready to be ingested the day you add it.

</Detail>

## One usage budget

Insights' token-budget meter uses your **real Anthropic account utilization** when the Terminal is installed (its usage-limits tracker), so Insights automatically backs off when you're using Claude elsewhere. Standalone, it can only estimate from its own runs.

## Power Tools make Insights smarter

Insights' analysis is only as good as the structure it reads. The Terminal's [Power Tools](/bruh-claude/power-tools/) are how that structure gets good:

- **Areas and floors** — room-by-room climate and presence analysis needs entities that actually have rooms. *"Put every unassigned entity in its right area"* is a one-liner.
- **Labels** — label your battery-powered devices once; device-health insights can group by it.
- **Sane names** — `light.kitchen_ceiling` reads better than `light.shelly_1pm_9a4c2f` in a chart and a voice reply alike.

<Detail min={2}>

- **[`import_statistics`](/bruh-claude/power-tools/blueprints-and-statistics/)** — backfill the gap from when your meter was offline, and the energy insight stops drawing a hole.
- **[`find_orphaned_references`](/bruh-claude/power-tools/diagnostics-and-repairs/)** — dead references become repair issues before they show up as anomalies in a report.

</Detail>

## The loop in practice

1. **Insights notices**: the nightly report flags that the garage fridge compressor runs 40% more than last month.
2. **You ask the Terminal**: *"pull the fridge's power history and compare it to the garage temperature"*.
3. **The Terminal acts**: creates an alerting automation, labels the fridge *watchlist*, files a repair issue if it's genuinely failing.
4. **Insights knows**: the finding is in shared memory, so the next report builds on it instead of rediscovering it.

The Terminal's own [insight jobs](/bruh-claude/automations/#insight-jobs) complement the panel: jobs for glanceable dashboard tiles and TTS briefings, the panel for interactive deep dives.
