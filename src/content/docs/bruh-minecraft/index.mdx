## What is BRUH Minecraft Server?

BRUH Minecraft Server is a Home Assistant add-on that runs a production-grade Minecraft server inside your HA installation — with a full management panel, automatic world backups, RCON, plugin management, Bedrock cross-play, and a first-class HA integration that exposes your server as sensors, buttons, and services.

No separate VPS. No proxy jars. No Microsoft account required (when you don't want it). It just works on the box you already trust to run your house.

## How It Works

The add-on bundles five things into one container:

- **Java 21 JVM** with Aikar G1GC tuning, configurable memory, and rate-limited crash auto-restart.
- **Server jar manager** that downloads the right Paper / Purpur / Folia / Vanilla / Fabric / Forge build and caches it under `/data/server-cache/`.
- **Ingress panel** (Python + SSE) for live monitoring and admin actions.
- **RCON client** for in-game commands (loopback-only, auto-generated 32-char password).
- **Bridge to Home Assistant** — a file-based IPC layer at `/config/.bruh_minecraft/` plus an auto-deployed custom integration.

## Quick Example

```yaml
# Nightly backup at 4 AM
automation:
  - alias: Minecraft - nightly backup
    trigger: { platform: time, at: "04:00:00" }
    action:
      service: bruh_minecraft.backup_now

# Auto-stop when nobody's playing
automation:
  - alias: Minecraft - auto-stop on idle
    trigger:
      platform: numeric_state
      entity_id: sensor.bruh_minecraft_players_online
      below: 1
      for: "00:30:00"
    action:
      service: bruh_minecraft.stop_server
```

Or just say *"tell everyone dinner is ready"* through Assist and it'll hit `bruh_minecraft.say` for you (when you have [BRUH Claude](/bruh-claude/) installed).
