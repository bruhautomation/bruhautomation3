<Release version="1.10.0" date="July 29, 2026" latest>
<Changes type="changed">

- **The add-on is spelled [brAIn](/brain/)**, everywhere on the site. The mark already read that way — the gable is the `A`, and the `A` and `I` are the one part drawn in the accent colour — so this is the text catching up with the logo.
- **The brAIn changelog is current again**, with the 1.6.0 (new mark), 1.7.0 (Findings, the two-verb ask bar, editable tags) and 1.8.0 (the rename, memory filing that empties its list, one usage pill carrying session *and* week) releases it was missing.
- **Usage and memory docs match the panel** — [Insights](/brain/insights/) and the [Reference](/brain/reference/) describe the two-window usage pill, and [Memory & Learning](/brain/memory/) describes what "File into memory now" does to the queue.

</Changes>
</Release>

<Release version="1.9.0" date="July 29, 2026">
<Changes type="changed">

- **New [brAIn](/brain/) mark.** The logo is now a descendant of the BRUH Automation logo rather than a cousin of it: the `BR` ligature, the gable and the signal motif are lifted unmodified from the parent mark, and the gable *is* the `A` in the wordmark. The old hero was a generic neural-mesh tile that could have belonged to any AI product.
- **The hero is the full wordmark, not an icon.** At hero size there is room for it, and the mark only reads as "brAIn" when the gable is doing its job as the `A`. Its `B`, `R` and `N` flip between ink and paper, so light and dark each get their own file rather than one image that half-disappears on one of them.

</Changes>
</Release>

<Release version="1.8.0" date="July 29, 2026">

The two app sections became one: **BRUH Terminal** and **BRUH Insights** were merged into a single add-on, [**brAIn**](/brain/), so their docs merged too.

<Changes type="added">

- **[brAIn docs](/brain/)** — Overview, Quick Start, Memory & Learning, Insights, Voice, Automations, MCP Tools, The CLI, Power Tools, and a Reference covering every option of the merged add-on. New pages for what brAIn added: the study-first onboarding that replaces default cards, the guess-and-settle memory model, the `brain`/`ha` CLI split, and `brain undo`.
- **A [brAIn changelog](/brain/changelog/)** starting at 1.0.0 — brAIn is a clean start, so its version numbers begin again rather than continuing either predecessor's.
- **Archived changelogs** for [BRUH Terminal](/brain/archive/bruh-terminal-changelog/) (1.0.0–3.6.0) and [BRUH Insights](/brain/archive/bruh-insights-changelog/) (1.0.0–1.7.0), kept in full and clearly marked, so the history of both add-ons stays readable.

</Changes>
<Changes type="changed">

- **Every `/bruh-claude/…` and `/bruh-insights/…` URL redirects** to its successor. Those links are in add-on changelogs, video descriptions, and bookmarks; pages with no direct successor land on the section that now covers them rather than a bare index.
- **New brAIn artwork** in the hero and the sidebar, replacing the separate Terminal and Insights icons.
- **"Using with Insights" is gone**, along with the whole idea of connecting two add-ons — one login and one memory is now just how it works, documented where it belongs.

</Changes>
<Changes type="fixed">

- **Docs that described removed behaviour** — git config backups (replaced by an edit journal and `brain undo`), the retired `ha-*` script pile, and the nine default insight categories.

</Changes>
</Release>
