<Release version="1.12.0" date="July 31, 2026" latest>

New lead copy on the [brAIn overview](/brain/), matching the READMEs and the add-on's own documentation, plus a correction to what the docs claimed brAIn can't do to YAML.

<Changes type="changed">

- **The overview leads with the pitch, not the parts list.** *Your house already has nerves. Now give it a brAIn.* The "What it is" section that follows says what the thing does in four short paragraphs — sees the whole system and can change any of it, keeps a memory you can open and edit, reachable as a conversation agent or a chat interface or native Claude Code, callable from your automations.

</Changes>
<Changes type="fixed">

- **brAIn can edit YAML-defined dashboards, helpers and persons** — the docs implied otherwise in four places. The registry *services* decline them, because a `brain.*` service edits the registry and a YAML-defined object isn't in it; brAIn then opens the file, edits it, validates it and reloads the domain. Same outcome, different layer, and `brain undo` covers both. It was listed under "deliberately excluded", which read as a gap in what brAIn can reach rather than the routing detail it is. Now explained at [YAML config is not an exception](/brain/how-brain-controls-ha/#yaml-config-is-not-an-exception).
- **The dashboards page no longer promises a git config backup** that was removed from the add-on some releases ago. Dashboard edits are covered by the automatic per-dashboard config backup and by `brain undo`.

</Changes>
</Release>

<Release version="1.11.0" date="July 31, 2026">

The brAIn docs were describing version 1.8 of an add-on that is now on 1.14. Two of the five panel tabs had no page at all, the site's most-repeated number was wrong in six places, and there was not a single picture of the product anywhere. All three are fixed.

<Changes type="added">

- **[Findings](/brain/findings/)** — a page for the tab that had none. What a finding is and how it differs from a memory line or a guess, the kinds of thing it actually catches, what **Fix it** is allowed to do (and the five things it will never do), **Discuss**, **Remind me later**, and why the two endings delete the card instead of filing it somewhere.
- **[Terminal](/brain/terminal/)** — the other missing tab. The two faces and the one session behind them, the switch that carries the conversation both ways, the command palette, the ⋯ menu, and what the tab does on a phone.
- **Screenshots.** Insights, Findings, Memory, the Terminal in chat mode, and the panel on a phone — on the [overview](/brain/) and on each feature page.
- **Panel settings are documented as a group** in the [Reference](/brain/reference/#panel-settings): what lives in ⚙ rather than the add-on Configuration tab, and takes effect without a restart.
- **`brain.answer_question`**, the [undo journal](/brain/cli/#undo) with worked output, `brain memory undo`, and the nine [Power Tools](/brain/power-tools/) that shipped in 1.9.0 — `rename_label`, `update_label`, `delete_device`, `delete_orphaned_devices`, `delete_integration`, `set_area_icon`, `update_floor`, `rename_person` — all previously undocumented.

</Changes>
<Changes type="changed">

- **The overview leads with what brAIn *does*.** It used to open with an inventory of parts ("a terminal, a dashboard, and a memory") and a block diagram of the container's IPC. It now opens with the product's own line — *give your smart home a mind* — a screenshot, and one card per thing it does.
- **The sidebar follows the product.** The four panel tabs are grouped under **The Panel** in the order they appear in the panel, voice and automations under **Beyond the Panel**, and the architecture pages under a collapsed **Under the Hood**.
- **65 Power Tools, not 56** — corrected in all six places it was stated, along with the stale per-family counts.
- **The Reference stops duplicating the feature pages.** Its panel tour was where "four tabs" and the ttyd-only Terminal description had been quietly rotting; it is now a table that points at the four pages that own those subjects.

</Changes>
<Changes type="fixed">

- **The brAIn changelog runs to 1.14.0 again**, nine releases on from where it stopped — including the two memory fixes worth knowing about ([1.11.2](/brain/changelog/) and 1.12.1).
- **The usage pill is a press, not a hover.** Three pages said hover; the control has been a press-to-open popover since 1.8.0, deliberately, because a tooltip is unreadable on a phone.
- **Memory docs no longer describe a group that was deleted.** The "Already in memory" list went away in 1.9.0; the docs still told you to use a ✕ that isn't there.
- **brAIn *can* remove an integration** — `brain.delete_integration` shipped in 1.9.0, but the scorecard still listed removal alongside adding as something it can't do.
- **A dead stylesheet rule** targeting `data-page-slug="bruh-claude"` has not applied since the rename; removed rather than revived.

</Changes>
</Release>

<Release version="1.9.0" date="July 29, 2026">
<Changes type="changed">

- **New [brAIn](/brain/) mark.** The logo is now a descendant of the BRUH Automation logo rather than a cousin of it: the `BR` ligature, the gable and the signal motif are lifted unmodified from the parent mark, and the gable *is* the `A` in the wordmark. Its `B`, `R` and `N` flip between ink and paper, so light and dark each get their own file rather than one image that half-disappears on one of them.

</Changes>
</Release>

<Release version="1.8.0" date="July 29, 2026">

The two app sections became one: **BRUH Terminal** and **BRUH Insights** were merged into a single add-on, [**brAIn**](/brain/), so their docs merged too.

<Changes type="added">

- **[brAIn docs](/brain/)** — Overview, Quick Start, Memory & Learning, Insights, Voice, Automations, MCP Tools, The CLI, Power Tools, and a Reference covering every option of the merged add-on. New pages for what brAIn added: the study-first onboarding that replaces default cards, the guess-and-settle memory model, the `brain`/`ha` CLI split, and `brain undo`.
- **A [brAIn changelog](/brain/changelog/)** starting at 1.0.0 — brAIn is a clean start, so its version numbers begin again rather than continuing either predecessor's.
- **Archived changelogs** for [BRUH Terminal](/brain/archive/bruh-terminal-changelog/) (1.0.0–3.6.0) and [BRUH Insights](/brain/archive/bruh-insights-changelog/) (1.0.0–1.7.0), kept in full and clearly marked, so the history of both add-ons stays readable.

</Changes>
<Changes type="changed">

- **Every `/bruh-claude/…` and `/bruh-insights/…` URL redirects** to its successor. Those links are in add-on changelogs, video descriptions, and bookmarks; pages with no direct successor land on the section that now covers them rather than a bare index.
- **New brAIn artwork** in the hero and the sidebar, replacing the separate Terminal and Insights icons.
- **"Using with Insights" is gone**, along with the whole idea of connecting two add-ons — one login and one memory is now just how it works, documented where it belongs.

</Changes>
<Changes type="fixed">

- **Docs that described removed behaviour** — git config backups (replaced by an edit journal and `brain undo`), the retired `ha-*` script pile, and the nine default insight categories.
