## What it is

A Home Assistant add-on that puts **Claude** to work as your home's analyst. It collects a slimmed snapshot of your HA data — entity states with areas, recent history, long-term energy statistics — sends it to Claude with a strict design system, and renders the result as a self-contained interactive visualization in an **Insights** panel in your sidebar. Every card comes with sharp written analysis, highlight stats, hover tooltips, animations, light & dark mode, and a colorblind-safe palette — designed specifically for *your* data.

## Works with your Claude subscription

No API key required. Connect once with your Claude **Pro or Max** account using the guided sign-in in the panel<Detail inline min={2}> (or paste a token from `claude setup-token`)</Detail>. An Anthropic API key works too if you prefer pay-as-you-go. Running BRUH Terminal too? [One login, one shared memory →](/bruh-claude/better-together/)

## What it doesn't do

Insights **analyzes; it doesn't act**. It won't flip a switch, change a setting, or reorganize anything — that's [BRUH Terminal](/bruh-claude/)'s job. It also never sends data anywhere except to Claude during a generation you scheduled or clicked, and person GPS coordinates never leave the house at all.

## Private by design

- Home data is sent to Anthropic's API only when an insight is generated — nothing else leaves your machine.
- Person **GPS coordinates are never included** in snapshots; only zone/state and areas are.
- Visualizations render in **sandboxed iframes** — they can't touch your HA session or cookies.
- The panel is only reachable through HA **Ingress** (admin users); the optional dashboard-card server is unmapped by default and token-protected.
- The `/config` mount is **read-only**.
