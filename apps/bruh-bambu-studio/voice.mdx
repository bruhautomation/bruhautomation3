With [brAIn](/brain/) installed, you can ask about your printers, start prints and design parts
from brAIn's chat, its terminal or a voice assistant.

## What to ask

| You say | What brAIn does |
|---|---|
| *How long is left on the print?* | Reads the printer's state, progress, time left and layer |
| *What's loaded in the AMS?* | Reads each tray's colour, material and how much is left |
| *Pause the printer.* / *Resume it.* | Pauses or resumes the current print |
| *Turn the printer light on.* / *Print in silent mode.* | Switches the chamber light, changes the speed |
| *Print the benchy on the X1C.* | Finds the file in `/share/bambu` and prints it, slicing first if needed |
| *Print this Printables model* (a link, typed in the chat) | Imports the model and prints it, or lists the files when the page has several |
| *Design a 4 cm wall hook with two screw holes and print it.* | Starts a part on the Design tab. The conversation prints it once it has built |
| *Make the coat hook 6 cm long.* | Sends the change to that part's design conversation |
| *Is the coat hook done?* | Says whether it has built, its size, brAIn's reply and any print |

A part designed from the chat or by voice is the same part, with the same versions and print,
on the [Design tab](/bruh-bambu-studio/design/) afterwards.

## What voice may and may not do

A voice assistant gets a narrower set than the chat, because a misheard sentence at a printer
costs filament and hours.

| By voice | Allowed |
|---|---|
| Check on a print, the AMS, the files | **Yes** |
| Pause and resume | **Yes** |
| Change the speed and the chamber light | **Yes** |
| Set a nozzle or bed temperature | **Yes**, refused while printing as everywhere |
| Start a print **of a file** in `/share/bambu` | **Yes** |
| Design a part, change it, ask how it is doing, and print it | **Yes**, up to **4 copies**. It never waits on a build: it says the part is being made |
| **Stop** a print | **No**. It cannot be undone |
| Send **G-code** or **home** the axes | **No** |
| **Slice** a file | **No** |
| **Import a link**, or start a print from a URL | **No** |
| **Open** a file in Bambu Studio | **No** |

A refused request is refused with a sentence saying so, and the voice assistant does not look
for another route. Everything refused by voice still works from brAIn's chat, its terminal,
the panel and automations. brAIn's [Voice](/brain/voice/) page covers the voice levels.

## What brAIn does before it acts

- **It starts a print straight away on a ready printer.** A printer that is not printing or
  paused is ready, and brAIn does not ask whether the plate is clear. A busy printer refuses,
  with the reason.
- **It confirms before stopping a print**, in the chat, because a stop cannot be undone.
- **MakerWorld links are refused.** They need your own Bambu sign-in.

<Aside type="note" title="The action gate">
`bambu_print`, `bambu_control`, `bambu_slice` and `bambu_design` go through brAIn's
[action gate](/brain/safety/), like every brAIn tool that changes something. Blocked services
and protected-entity rules apply too. Asking how a designed part is doing
(`bambu_design status`) only reads, and is not gated.
</Aside>

## The tools

brAIn offers these tools only when the `bruh_bambu` integration is set up. Each one calls a
`bruh_bambu` service.

| Tool | What it covers |
|---|---|
| `bambu_status` | Each printer's state (idle, prepare, running, pause, finish, failed, offline), progress, minutes left, layer, temperatures and targets, speed, light and AMS trays, whether Bambu Studio is running and the latest jobs. Optionally the files in `/share/bambu`. Read-only |
| `bambu_print` | `start` a file (or a Printables / `.stl` / `.3mf` link), with `slot`, `material`, `plate`, `use_ams`, `timelapse`. `pause`, `resume`, `stop` the current print |
| `bambu_control` | `speed`, `light`, `temperature` (nozzle 0–300 °C, bed 0–120 °C, refused while printing), `home`, `gcode` (up to 32 lines, refused while printing) |
| `bambu_slice` | Slice a file with Bambu Studio's command line into `/share/bambu/sliced` |
| `bambu_design` | `create` a part, `message` a change, `status` of one part or all, `print` a built part with printer, version, copies, tray and settings |
