The **Studio** tab is Bambu Lab's own Bambu Studio, running inside the app and shown in your
sidebar. Everything you do in it on a desktop works here: open a model, paint supports, arrange
a plate, sign in to MakerWorld, slice, save a project.

## Use it on a computer

The mouse and keyboard go straight through. Use it as you would on your desktop.

## Use it on a phone or tablet

| Do | How |
|---|---|
| Click | Tap |
| Right-click | Hold |
| Zoom and move around | Two fingers |
| Choose what one finger does | **Move** (the view), **Drag** (sliders and the 3D view) or **Scroll** on the toolbar |
| See the whole screen again | **Fit** |
| Type | **Keyboard**, with **Backspace**, **Enter** and **Done** beside it |

## Move files in and out

Bambu Studio's Open and Save dialogs reach `/share/bambu`, the same folder as the
[Files tab](/bruh-bambu-studio/printing/#add-models-to-the-library).

- **Save a project there** and it appears in Files, ready to print from anywhere.
- **Open in Studio** on any file, or **Open in Bambu Studio** on a designed part, opens it on
  this tab.

<Aside type="tip" title="MakerWorld">
MakerWorld models need a signed-in Bambu account. Sign in on Bambu Studio's MakerWorld page
here and open the model. Nothing else in the app needs a Bambu account.
</Aside>

## Choose the version and screen size

| Option | What it does |
|---|---|
| `bambu_studio_version` | `latest` takes the newest release on first start and keeps it. A release tag such as `v02.08.02.61` stays on that version. Changing it downloads that one on the next start |
| `appimage_url` | A direct AppImage link, for when GitHub is unreachable |
| `screen_resolution` | The screen Bambu Studio draws on, `1600x900` by default. The panel scales it to your window. A larger screen shows more of the slicer and makes text smaller on a phone |

See [Reference](/bruh-bambu-studio/reference/) for all options.

## Good to know

- **The first start downloads about 220 MB** from Bambu Lab's GitHub releases. The tab shows
  the progress. The download is kept, and left out of backups because the app can fetch it
  again.
- **If Bambu Studio's window closes, it starts again.** If it stops, the tab says so, offers
  **Start**, and shows its last lines of output under *What it last printed*.
- **Only a signed-in administrator can reach it.** The screen is served through Home
  Assistant's ingress and nowhere else.
- **A large model's 3D view is slow.** The app has no graphics card to use. Slicing is
  unaffected.
- **Prints started elsewhere do not change what you have open.** They slice separately. On a
  machine short of memory the window closes while that slice runs and opens again on the same
  file afterwards. The tab says so meanwhile.
- **Missing libraries are named.** If a new Bambu Studio release needs a system library the
  app lacks, the tab lists it. Update the app or pin an older Bambu Studio version.
