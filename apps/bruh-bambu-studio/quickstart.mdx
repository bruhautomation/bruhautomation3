Go from nothing to a print started from Home Assistant in about ten minutes. Most of that is
the slicer downloading.

## Before you start

| You need | Where to find it |
|---|---|
| An **amd64 (x86-64)** machine running Home Assistant OS or Supervised, 2024.7.0 or newer | The app does not install on a Raspberry Pi |
| The printer's **access code** | The printer's screen, in its network settings (*LAN Only*, or *WLAN* on the A1 and P1) |
| **LAN-only mode** and **Developer mode** on | The printer's screen. Without them a recent printer reports its status but answers a command with *"The printer did not confirm it"* |
| A fixed address for the printer (recommended) | Your router |

## Install

<Steps>

1. **Add the repository.** In Home Assistant, open **Settings → Add-ons → Add-on Store → ⋮ →
   Repositories** and paste:

   ```text title="Repository URL"
   https://github.com/bruhautomation/BRUH-HA-Apps
   ```

2. **Install BRUH Bambu Studio** and press **Start**. The defaults suit almost everyone. The
   [reference](/bruh-bambu-studio/reference/) lists every option.

3. **Open Bambu Studio in the sidebar** and let it download. The **Studio** tab shows
   *Downloading…* with a percentage (about 220 MB), then *Unpacking…*. Later starts use the
   copy already there.

4. **Restart Home Assistant once.** The **Printers** tab shows a banner with a **Restart Home
   Assistant** button. After the restart, the integration is under **Settings → Devices &
   services** with a device per printer. Until then there are no sensors, camera, services or
   dashboard card.

</Steps>

<Aside type="tip">
An update asks for another restart only when the integration's code changed. Otherwise a page
reload is enough.
</Aside>

## Add a printer

<Steps>

1. **Open Settings › Printers** in the panel. An empty **Printers** tab sends you there.
   **Find printers** runs by itself the first time and lists each Bambu Lab printer on Home
   Assistant's network with its model, serial number and address.

2. **Press Add** beside your printer and type its **access code**.

3. **Press Save.** The panel waits for the printer to answer and says whether it did. The
   printer's card appears on the **Printers** tab.

4. **Set its model** if the panel did not fill it in. The model decides which Bambu Studio
   profiles a print is sliced with. The printer's name does not.

</Steps>

| If | Do this |
|---|---|
| The scan misses a printer on another network | Use *Search a different network* with its range, such as `192.168.2.0/24`. The scan covers each of Home Assistant's networks up to a /22 and needs port 8883 |
| You want to add it yourself | Open *Add a printer by hand* and give the **IP address** (Network on the printer's screen), the **serial number** (Settings → Device) and the **access code** |
| A printer moved to a new address | **Find printers** offers **Update address**, which keeps its access code |

<Aside type="note" title="Access codes stay out of backups">
Access codes are left out of Home Assistant backups. After restoring a backup, add each code
again. The code also changes whenever LAN mode is switched off and on.
</Aside>

## Start your first print

<Steps>

1. **Put a model in the library.** Use **Upload** on the **Files** tab, copy it into
   `/share/bambu` over Samba, or paste a Printables page or a direct model link into the import
   box and press **Import**.

2. **Press Slice & print** on its row. Choose the printer and, for a bare model such as an STL,
   the AMS tray or the external spool. Leave the
   [print options](/bruh-bambu-studio/printing/#print-options) alone to use Bambu Studio's
   profile.

3. **Watch it** on the **Printers** tab: the camera, the stage, a progress ring, the time left
   and the time it finishes.

</Steps>
