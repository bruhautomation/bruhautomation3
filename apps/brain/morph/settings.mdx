Set up Morph in brAIn's ⚙, and edit its files in `/config/morph` when you want to. This page
lists every setting and every key of `dashboard.yaml`.

## The switch: ⚙ › Features

Morph is one of brAIn's [four switches](/brain/features/). Each takes effect at once, with no
restart.

| Switch | What it does for Morph | Default |
| --- | --- | --- |
| **Morph dashboard** | The first tab, and Morph's service inside brAIn. Off, the service does nothing. | Off on a fresh install; on if you upgraded from the Morph app. |
| **Learning loop** | Morph's usage log, learning passes and lessons (with the rest of brAIn's learning). [How it learns](/brain/morph/learning/). | On |
| **Development loop** | Lets Morph's faults and the issues you choose to open reach brAIn's private reports repository. Nothing leaves the house without it. | Off |
| **Personality** | The name you gave brAIn appears in Morph too (*"hold anything to tell Nova what to change"*). | On when a personality is set |

## ⚙ › Dashboard

Morph's settings are the **Dashboard** section of brAIn's ⚙. It shows while the Morph dashboard
is on.

![brAIn's Settings, dark theme, on the Dashboard section: the experimental notice, Changes with "Model for changes" set to brAIn's default and "How long a hold takes" set to Normal, Appearance with the theme set to Follow Home Assistant and a Reduce motion switch, and Header tabs with the first tab's name and icon](./images/dashboard-settings.webp)

| Part | Setting | Choices |
| --- | --- | --- |
| **Changes** | Model for changes: the model a Tell uses | brAIn's default, Sonnet, Opus, Haiku |
| | How long a hold takes | Quick, **Normal**, Slow |
| **Appearance** | Theme | **Follow Home Assistant**, Dark, Medium, Light |
| | Reduce motion: things move straight to where they belong | Off |
| **Header tabs** | Each of brAIn's four tabs: its name and its icon (the first is **Morph UI** with a dashboard icon unless you change it) | |
| **Learning loop** | How often | Twice a day, **Daily**, Every 3 days, Weekly |
| | Which model | brAIn's default, Haiku, Sonnet, Opus |
| | **Learn now**, the scorecard, and the lessons (`LEARNED.md`) to read and edit | |
| **Changes to the dashboard's own code** | Every change this house made to Morph's code, in use or paused, with **Remove my change** (and **Update** / **Update all** for a paused one) | |
| **History** | Every change with who made it (You, brAIn, Learning, Outside), and **Undo** or **Restore** for each | |
| **Rebuild** | **Rebuild from the house**, itself a commit you can undo | |

Whether the learning loop runs at all is the switch in ⚙ › Features.

## The files

`/config/morph/` is a git repository. Edit any of these by hand and Morph commits your edit as
*Edited outside Morph*.

<FileTree>
- config/
  - morph/
    - dashboard.yaml the dashboard: floors → sections → groups → cards
    - AGENTS.md how Morph is built, for brAIn: the schema, the card types, the design rules
    - LEARNED.md what this household has taught Morph
    - cards/ custom card code brAIn writes, a Lovelace custom element per file
    - frontend/ your copies of Morph's own modules, when brAIn changed one
    - dashboards/ Home Assistant dashboards brAIn looks after, one YAML each
    - types/ card types, used on HA dashboards
    - themes/ Morph's Home Assistant themes
</FileTree>

<Aside type="tip" title="It is safe to back up and restore">
Everything Morph knows about your dashboard is in `/config/morph`, so a normal Home Assistant
backup carries it, history included. Uninstalling the old Morph app never touches it.
</Aside>

## dashboard.yaml

The dashboard is floors, then sections (rooms), then groups, then cards. A small, complete
example:

```yaml
title: Home
story: true
coming_up: true
scenes: [scene.morning, scene.evening, scene.all_off]
coming_up_lanes:
  - label: Laundry
    entities: [sensor.washer_status, sensor.dryer_status]
    running: [running]
floors:
  - title: Ground
    sections:
      - title: Kitchen
        color: amber
        width: 2
        icon: mdi:silverware-fork-knife
        groups:
          - cards:
              - type: scenes
                entities: [scene.kitchen_cook, scene.kitchen_off]
              - entity: light.kitchen_countertop
                name: Counter
              - type: lovelace
                card:
                  type: custom:mushroom-entity-card
                  entity: sensor.fridge_temperature
      - title: Living room
        color: violet
        groups:
          - cards:
              - type: light_group
                entity: light.living_room_lights
              - entity: media_player.living_room_tv
          - label: Party
            when:
              entity: input_boolean.party_mode
              state: "on"
            cards:
              - entity: switch.party_lights
  - title: Upstairs
    sections:
      - title: Alex's room
        color: sky
        sleep_guard: true
        cards:
          - entity: light.alex_lamp
          - entity: climate.upstairs
            options:
              actions: [script.bedtime_cool]
```

### The top

| Key | Default | What it does |
| --- | --- | --- |
| `title` | `Home` | The dashboard's name. |
| `greeting` | `true` | *Good morning*, *Good night*. |
| `story` | `true` | The verdict sentence under the greeting. |
| `ask` | `true` | The *Ask or tell the house…* line. |
| `coming_up` | `true` | The Coming up strip. |
| `coming_up_lanes` | none | Machines with a lane of their own in Coming up: each with `label`, `entities`, and optionally `running` / `not_running` (the states that mean running), `attribute`, `word`, `color`. Up to 12. |
| `scenes` | none | The house's scenes line. |
| `theme` | none | `auto`, `dark`, `medium` or `light`. |
| `night_dim` | off | `true` dims the page at night. |
| `floors` | none | The floors, in order. |

### Floors

| Key | What it does |
| --- | --- |
| `title` | The floor's name. |
| `heading` | `false` hides the floor's heading. |
| `sections` | Its rooms, in order. |

### Sections (rooms)

| Key | Default | What it does |
| --- | --- | --- |
| `title` | none | The room's name. |
| `color` | in turn | `amber`, `sand`, `sky`, `violet`, `teal`, `lime`, `rose`, `peach` or `indigo`. |
| `width` | `2` | Its share of the page, `1`–`4`. |
| `icon` | none | A faint icon before its name (`mdi:…`). |
| `area` | none | The Home Assistant area it is about. |
| `sleep_guard` | off | `true` holds what the page would do to this room while its sleeper is asleep, and asks first. |
| `hidden` | off | Hides the section. |
| `groups` | none | Groups of cards. `cards:` directly on the section is one group. |

### Groups

| Key | What it does |
| --- | --- |
| `label` | A small heading for the group (*PARTY*). |
| `note` | A short line under it. |
| `when` | `{entity, state}` or `{entity, state_not}`: shows the group only at those times. Either can be a list. |
| `cards` | The cards. |

### Cards

| Key | What it does |
| --- | --- |
| `type` | One of Morph's cards (below). Leave it out and Morph picks one from the entity. Any other type (`tile`, `custom:…`) is hosted as a Lovelace card. |
| `entity` / `entities` | What it shows. Scenes, Openings (`list`) and Readings take a list. |
| `name`, `icon`, `unit` | Override what Home Assistant says. |
| `span` | Its width, `1`–`4`. |
| `color` | One of the section colours. |
| `options` | Per-kind options, for example a thermostat's `actions` (up to four scripts or scenes as buttons, each optionally with `short`, `running`, `icon`, `color` and `modes`). |
| `text` | A note's words (`type: note`). |
| `card` | A hosted card's own config (`type: lovelace`). |

**Morph's card types:** `light`, `light_group`, `fan`, `fan_group`, `cover`, `cover_group`,
`lock`, `switch`, `button`, `vacuum`, `climate`, `sensor`, `readings`, `meter`, `media`, `camera`,
`list`, `person`, `weather`, `alarm`, `scenes`, `entity`, `note`, and `lovelace` for any other card.

Your own card kinds in `cards/` are types too, once brAIn has written them.

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| A hand edit to `dashboard.yaml` does not show | The file has a YAML error. The panel keeps showing the last good version, with the parser's message and line above it. Fix the file, or **Undo** the last change in ⚙ › Dashboard › History. |
| A bar at the top says to reload, or to restart Home Assistant | Morph's code on screen is older than what Home Assistant would serve. Reload. If brAIn was updated but Home Assistant still runs the older integration, restart Home Assistant once. |
| A note says one of my changes is paused | An update changed a module your copy of Morph's code builds on. Press **Update** to merge your change into the new version (one change you can undo), or **Not now** to keep Morph's own running. |
| Tell does nothing | Check that brAIn is signed in, that you are a Home Assistant administrator, and that brAIn's **Automation tasks** option (`enable_automation_integration`) is on. |
| The brAIn button is not on my dashboard | It shows for administrators only. A YAML-mode dashboard cannot be changed by brAIn, because Home Assistant cannot save it. |
