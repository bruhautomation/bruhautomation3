Hold a card, a room, a floor or the whole dashboard and tell brAIn what should be different.
brAIn looks at what you are looking at, makes the change, and gives you **Keep** and **Undo**.

![The Tell box open under the Kitchen's Countertop card in Edit, dark theme: "Tell Juniper" (the assistant's name in this house), a picture of the card labelled "How it looks now", the request "Make this the full width of the room and call it Counter.", a note that Send asks for versions and Just do it makes one change straight away, and Cancel, Just do it and Send for versions](./images/morph-tell-box-dark.webp)

## Tell brAIn about a card

<Steps>

1. **Open the Tell box.** Press the pencil (**Edit**) and hold the card. Outside Edit,
   right-click the card, tap it with two fingers, or point at it and press **T**.

2. **Check the picture.** Morph takes a picture of what you hold and shows it in the box.
   brAIn reads it first, so *"this is cut off"* means what is on your screen.

3. **Say what should change.**

4. **Choose how.** **Send for versions** asks for versions to pick from. **Just do it** makes
   one change straight away.

</Steps>

The same works for a room's title, a floor or the whole dashboard. There the box has one
**Send** button, which makes the change.

You can also type a change into the **Ask** line: *"remove the Coming up timeline"*, *"the
kitchen header is too tall"*. brAIn reads it as a change and makes it as a Tell.

### Things to tell it

| Kind | Examples |
| --- | --- |
| **Layout** | *"Put the porch light in Entry."* *"Move the Office above the Kitchen."* *"Make the thermostat the full width of the room."* |
| **Looks** | *"The kitchen header is too tall."* *"Make the cards rounder."* *"Use teal for the Office."* |
| **New cards** | *"Add a card with the washer and dryer and how long they have left."* *"Show the driveway camera in Garage."* |
| **Morph itself** | *"Add a switch in the header for the porch light."* *"The Coming up strip should start at 6 AM."* These change your copy of [Morph's own code](#changing-morph-itself). |

## Pick from versions

**Send for versions** gets two or three versions of the card. Each has a short name and one
line saying what is different. Morph draws them in the card's place with your house's real
states. Nothing changes while you choose.

![Three versions of a temperature card offered in its place, dark theme: the request "Make this simpler", the chips Current, A "Kitchen only", B "Inside" and C "Average", the line "B · Inside — Just the rooms people live in, one chart", arrows to step, and Use this, More like this, Change… and Discard](./images/morph-tell-versions-dark.webp)

| Control | What it does |
| --- | --- |
| **Current · A · B · C** | Shows that version. The arrows, the arrow keys and a sideways swipe step too. |
| **Use this** | Makes the shown version the card, as one change you can Undo. |
| **More like this** | Asks for variations on the shown version. |
| **Change…** | Revises that one version. |
| **Discard** | Leaves the card as it was. |

- A version that needs something new in Home Assistant, such as a template sensor, says so.
  It is made only if you pick that version.
- If the card changed after the versions were made, **Use this** becomes **Use it anyway**
  and **New versions**.
- The Tell box lists the card's **earlier versions**, the last five it replaced. Tap one to
  see it in place, and **Use this** puts it back.

## Watch it work and read the result

brAIn's steps appear in the box as it takes them, with how long it has been at it. Close the
box and the work carries on. A strip at the top of the dashboard says what brAIn is doing,
and **Show** opens the box again.

![A finished Tell, dark theme: the steps "Looking at the screenshot", "Reading dashboard.yaml", "Editing dashboard.yaml", "Changed dashboard.yaml", the answer "Made the cans card wider and moved it to the top of the kitchen", the lines Dashboard "Changed the card Cans in Kitchen", Home Assistant "Not changed" and GitHub "Nothing sent", what the assistant saw, and Keep, Undo and Tell it more](./images/morph-tell-result-dark.webp)

When brAIn answers, the change is one commit. You see the card **before and after**, and one
line for each place the request could reach:

| Line | What it reports |
| --- | --- |
| **Dashboard** | What is different on screen, read back from the file. |
| **Home Assistant** | Any change to the house itself. Only when you asked for one. |
| **Morph's code** | Shown when Morph's own code changed. |
| **brAIn's memory** | Facts about the house it queued along the way. |
| **GitHub** | *Nothing sent*, unless you say yes to an issue. |

Then choose:

| Button | What it does |
| --- | --- |
| **Keep** | Done. |
| **Undo** | Reverts exactly that commit. If you asked for a change in Home Assistant, it asks brAIn to put that back too. |
| **Tell it more** | Keeps the conversation, takes a new picture, and asks what should be different. |

If nothing changed, the box says *Nothing on the dashboard changed* and quotes brAIn. If
brAIn left `dashboard.yaml` unreadable, it says *Not applied*, Morph keeps showing the last
version that read, and **Undo** puts the file back. **Refresh** reloads a screen that has not
caught up.

### Answer a choice that is yours

Some choices come back as buttons. The commonest: a card that works out a number from other
sensors has no history, because Home Assistant only records entities. brAIn builds the card
and asks:

- **Calculate it in the card**, or
- **Make a Home Assistant sensor**, so the number is recorded.

The button that changes Home Assistant says so. Pressing one sends it as your next request.

## What a Tell may change

| Target | When |
| --- | --- |
| The dashboard, `/config/morph/dashboard.yaml` | At once. |
| Morph's card code, `/config/morph/cards/` | At once. |
| [Morph itself](#changing-morph-itself): header, layout, built-in cards, styles | At once, in your copy. |
| **Home Assistant itself**: entity ids, names, areas, automations, scripts, helpers | **Only when you ask for it in words**: *"change the entity ID"*, *"rename the device"*, *"make an automation that…"*. |

*"Call this card Counter"* renames the card. *"Rename the device to Kitchen counter"* renames
it in Home Assistant.

When a request would need a house change you did not ask for, brAIn does the dashboard part
and lists the rest under **Left for you**.

<Aside type="note" title="brAIn's safety still holds">
brAIn's [protected entities](/brain/safety/#protected-entities), its action gate and its edit
snapshots (`brain undo`) still apply. What brAIn learns about the house along the way goes
into brAIn's memory, not Morph's lessons.
</Aside>

## Edit by hand

Press the pencil (**Edit**) at the right of the page's first line. **Done** and **YAML**
appear in the header.

![Morph in Edit mode, dark theme: YAML and Done in brAIn's header, a hint line reading "hold anything to tell Nova what to change · drag a section by its title · tap a card to rename, resize or remove it", the Ask line now reading "Tell Nova how to change this dashboard", and each room with a drag handle and its own Edit](./images/morph-edit-dark.webp)

| Do | To |
| --- | --- |
| **Tap a section** | Rename it, recolour it, move it to another floor (or a new one), widen it, add a group, hide it or remove it. |
| **Tap a card** | Rename it, resize it, move it, edit its JSON, or remove it. |
| **Drag a section** | Reorder it, or move it between floors. |
| **Add card** (in each section) | Pick from the entities in that room, then any entity, then **Lovelace card** to paste any card's YAML or JSON. |
| **YAML** (in the header) | Open the dashboard as YAML. |
| **Hold anything** | Tell brAIn. |

Every save is one commit. The toast after a change offers **Undo**.

## Undo any change

`/config/morph/` is a git repository. Every change is one commit, with who made it: yours in
Edit, brAIn's in a Tell, the learning loop's, and a hand edit to the files.

- **⚙ › Dashboard › History** lists every change, with **Undo** or **Restore** on each. An
  undo is itself a commit, so it can be undone.
- **Edit the files by hand** if you like. Morph commits your edit as *Edited outside Morph*.
- **A broken file never blanks the page.** If `dashboard.yaml` stops parsing, the panel keeps
  showing the last version that did, with the parser's message and line above it.

## Changing Morph itself

brAIn can change Morph's own panel. It copies the module into `/config/morph/frontend/` and
edits the copy. Morph serves your copy after a page reload.

- The box offers **Reload to see it** and **Undo**.
- It then asks **Would you like to open an issue to update Morph's code?** Nothing is sent
  unless you press **Open an issue**.
- The change is in History like any other. Undo puts Morph's own back.
- A copy that does not load is not a blank page. Morph runs its own copy for that page load
  and says what went wrong.
- Your dashboard and your own cards (`cards/`) are never touched by an update.

### When an update pauses your change

If a brAIn update changes a file you changed, or a module your copy builds on, your change is
paused and Morph's own runs. A note offers:

| Button | What it does |
| --- | --- |
| **Update** | Merges your change into the new version, as one change you can undo. |
| **Not now** | Keeps Morph's own running. |

Where the update rewrote the same code your change was in, brAIn asks how to bring them
together, with a button for each way.

### When Morph's own code fails

Morph records a fault when a card fails to draw, a layout overlaps at rest, or it cannot read
an answer from brAIn. A request that needs Morph's code changed is recorded only when you
press **Open an issue** or **Send as issue**. brAIn being slow or signed out is not recorded.

Nothing leaves your house unless brAIn's **Development loop** switch (⚙ › Features) is on.
With it on, brAIn files each fault once in your private reports repository, redacted.
