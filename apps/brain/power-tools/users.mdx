Ask brAIn to make a login for a guest, switch it off when they leave, and remove it later.

## Ask brAIn

```text
Set up a login for the babysitter. No admin rights.
Disable the account we made for the house sitter.
Re-enable the babysitter's account.
The house sitter's gone. Delete their account entirely.
```

An automation can call the same services, for example to disable the kids' accounts after bedtime.

## What brAIn can do

Every service is admin-only. Call one from **Developer tools → Actions**, a script or an automation, or ask brAIn. \* marks a required field, and `[]` marks a field that takes one value or a list.

| Service | What it does | Fields |
| --- | --- | --- |
| `brain.create_user` | Create a user account. `username` and `password` go together, and the password needs at least 8 characters. `admin` defaults to off. Returns the new `user_id`. | `name`\*, `username`, `password`, `admin` |
| `brain.enable_user` | Re-enable disabled accounts. Returns the users enabled. | `user_id[]`\* |
| `brain.disable_user` | Disable accounts. | `user_id[]`\* |
| `brain.delete_user` | Delete accounts and their credentials. `dry_run: true` lists what would go. | `user_id[]`\*, `dry_run` |

To list users and when each last signed in, or to change a user's role, see [`list_users` and `set_user_group`](/brain/power-tools/system/#integrations-groups-users-and-dashboards).

<Aside type="tip" title="You cannot lock yourself out">
`disable_user` and `delete_user` refuse the owner, system-generated users and the last remaining administrator.
</Aside>

Find a `user_id` by asking brAIn, or with `brain.list_users`. brAIn confirms with you before it disables or deletes a user. New voice agents start with `brain.*` blocked, so a voice agent cannot create a login unless you allow it.

## Examples

```yaml title="A login with no admin rights"
action: brain.create_user
data:
  name: Babysitter
  username: babysitter
  password: "correct-horse-battery"
response_variable: user   # user.user_id
```

```yaml title="Disable an account"
action: brain.disable_user
data:
  user_id:
    - 1234567890abcdef
```
