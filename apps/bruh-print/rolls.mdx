The **Printer** tab is where you say which labels are loaded, line up a roll, manage the stock
catalog and set print quality. It has four sections: **Printer**, **What is loaded**, **Label
stock** and **Settings**.

![The Printer tab: the LabelWriter 450 Twin Turbo card with Idle, Check paper and lid and Show connection info, and What is loaded with a left and a right roll, each with a label picker, About N left — press to correct, Full roll, Not lined up yet, Line up this roll and Print a check label](./images/printer.webp)

## Say what is loaded

Under **What is loaded**, pick the label in each roll. A LabelWriter cannot report this itself.

Once you have, three things follow:

- **A label that does not match the roll is refused.** Without that check, a 2.25″ label sent to a
  0.56″ roll prints across the backing paper, once per copy, with no error anywhere.
- **Nothing asks you which roll.** You pick a label on the Quick tab, in the designer, on a
  template, on the card or in a service call. BRUH Print sends it to the roll that holds it.
- **Pickers list only what is loaded.** The whole catalog appears on the Printer tab alone.

From an automation, `bruh_print.set_roll` records a new roll.

## Use two rolls on a Twin Turbo

A **LabelWriter 450 Twin Turbo** shows a **Left roll** and a **Right roll**. The chip at the top of
every tab names both, and marks one **prints text**. That is the roll plain text goes to.

Change it in any of three places, which all share one setting:

- the **Prints on** line on the Quick tab
- a roll tile on the dashboard card
- the `bruh_print.choose_label` service

The printer sensor's `text_prints_on` attribute reports it. A printer with one roll never shows a
control for a second.

## Keep count of what is left

Each loaded roll says *About N left — press to correct*. The count is an estimate, counted down
from your prints, because a LabelWriter reports no real level.

| To do this | Do this |
| --- | --- |
| Correct the count | Press the count and type the real number |
| Start a new roll | **Full roll** |
| Stop counting | **Settings → Keep an estimate of how many labels are left**, off |

A roll running low is marked in the top bar, on the Printer tab and on the card.

## Lining up a roll

Do this once for each roll. Where a printer starts laying ink depends on the roll, so labels can
print a few millimetres down or to one side, the same amount every time. Lining up measures where
the printable area is, and BRUH Print lays labels out inside it.

![The Line up dialog at the step Where the label sits on the grid: Print the grid again, notes on which way up to hold the label, which scale is which and what the numbers are, a drawing of a label over the grid with X1, X2, Y1 and Y2 marked, and the boxes to type them into](./images/line-up.webp)

<Steps>

1. Press **Line up this roll** on the roll, then **Print**. One label comes out with a numbered
   grid. The grid runs past the label onto the backing and the next label, on purpose.
2. Hold the label with the small numbers at the top. That end came out first.
3. Type in the four readings from the table below. Numbers are millimetres, with a number every
   5 mm and a tick every 1 mm.
4. Press **Apply**. BRUH Print says in one sentence what your printer does with this roll.
5. Press **Print a check label**. A complete frame reading *Should reach every edge* means you are
   done. A missing side shows which way it is out.

</Steps>

| Reading | Where to read it |
| --- | --- |
| **X1** | Where the label's **left** edge falls on a black strip (white numbers, running across) |
| **X2** | Where the **right** edge falls on that strip. Leave it empty if the strip stops short of the edge. |
| **Y1** | Where the **top** edge falls in a plain column (black numbers, running down). Enter **0** if the top edge is above the grid, which is the common case. |
| **Y2** | Where the **bottom** edge falls in that column |

To correct a roll later, open **Line up this roll** again. Its numbers come back filled in, and
**Print the grid again** and **Print a check label** are both in the dialog.

| To do this | Do this |
| --- | --- |
| Keep part of the label blank | **Where to print on it**: a number each for **Top**, **Bottom**, **Left** and **Right** |
| Match the top and bottom borders | **Even up the ends** fills in the bottom number for you |
| Set an even border on all four sides | The stock's margin, under **Rename or resize** |
| Throw the measurement away | **Forget the lining up**. The roll goes back to printing as if it had never been measured. |
| Feed out a held label | **Feed**, shown only on a roll set to hold its last label inside so the next print lines up |

## Manage label stock

![The Label stock section: rows for Pantry labels in the left roll, Wrap-around labels in the right roll, Address, Multipurpose, Return address and Shipping, each with its two measurements, border and part number, a Text direction picker, Rename or resize and Hide or Delete](./images/label-stock.webp)

A stock is two measurements, and they are not interchangeable:

- **Across the print head**: the width the head covers in one pass.
- **Along the roll**: how far the paper travels for one label.

| To do this | Do this |
| --- | --- |
| Add your own labels | **Add a stock**: a name and the two measurements. SKU, labels per roll and margin are optional. |
| Fix a label that comes out rotated, text off the edge | **Rename or resize → These are the wrong way round** |
| Change which way text runs | **Text direction** on the stock's row. It applies to every print on that stock. |
| Call a roll what you call it | **Rename or resize**. Every picker uses the new name. |
| Change the blank border (2 mm by default) | **Rename or resize** |
| Set how many labels a full roll holds | **Rename or resize** |
| Remove a stock from the list | **Hide** for a built-in stock, **Delete** for your own |

**Text direction** starts on automatic. A label much longer than it is wide is treated as a
wrap-around label, so its text runs along the roll. The picker shows which way automatic decided.

Editing a built-in stock saves your own copy, so an update never undoes your measurement.

## Set print quality

![The Settings section: If nothing comes out set to Standard, Darkness set to Dark, Print speed set to Slow and dark, and checkboxes for Refuse a label whose stock is not in the roll, Quick labels are UPPERCASE and Keep an estimate of how many labels are left](./images/settings.webp)

| Setting | Default | What it does |
| --- | --- | --- |
| **If nothing comes out** | Standard | Change it when the printer takes a job and prints nothing. Try *Compact* next, then *Bare minimum*, pressing **Print a check label** after each. |
| **Darkness** | Dark | *Dark*, *Normal*, *Medium* or *Light*. Turn it down if labels smudge or curl. |
| **Print speed** | Slow & dark | The printer's "barcodes and graphics" mode: darker, and more accurate for barcodes and QR codes. *Fast* roughly halves the time of a long run. |
| **Refuse a label whose stock is not in the roll** | On | The stock check. Leave it on. |
| **Quick labels are UPPERCASE** | Off | Capitalises every Quick label |
| **Keep an estimate of how many labels are left** | On | Off stops the count |

<Aside type="caution" title="Bare minimum on a Twin Turbo">
*Bare minimum* stops sending roll select, darkness and speed. A Twin Turbo then prints on
whichever roll it used last, so use this mode only when the other two print nothing.
</Aside>

## Check the printer

On the printer's card:

- **Check paper and lid** asks the printer whether it has labels and its lid is shut. It prints
  nothing.
- **Show connection info** lists the resolution, serial number and USB endpoints, for a bug
  report.
