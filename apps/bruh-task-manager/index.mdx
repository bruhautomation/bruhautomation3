BRUH Task Manager is the Task Manager your PC has, for Home Assistant OS. It lists every app
busiest first, with its CPU, memory, network and disk, and lets you restart or stop the one
that is slowing the machine down.

![BRUH Task Manager's Apps tab: four meters across the top (CPU 39%, Memory 62% — 2.3 GB of 3.7 GB, Load 1.42 on 4 CPUs, Up 4 days 13 hours), then Studio Code Server at 84% CPU marked "high CPU for under a minute", Home Assistant at 9.2%, the Supervisor, BRUH Task Manager itself and Mosquitto, each with memory, network and disk rates and Processes, Restart and Stop buttons](./images/apps.webp)

<Aside type="caution" title="Experimental">
BRUH Task Manager is marked **experimental** in the app store.
</Aside>

## What you can do

### See what is using the machine

| You do | What happens |
|---|---|
| Open **Task Manager** in the sidebar | Four meters show the whole machine: **CPU**, **Memory**, **Load** and **Up**. |
| Look at the **Apps** tab | Every app, Home Assistant, the Supervisor and its plugins, busiest first. Each row has CPU, memory, network and disk, and a line for the last few minutes. |
| Search, or sort by CPU, memory or name | The list narrows or reorders. |
| Turn on Level 2 and open **Processes** | Every process on the machine, grouped by the app it belongs to, with its pid and command line. |

![The Processes tab: 19 processes grouped by app. Studio Code Server's group (27%, 1.2 GB, 3 processes) shows two node processes with End buttons and its s6-svscan supervisor, which explains that ending it stops the whole app. Home Assistant's group says to use Restart instead and lists python3, an ffmpeg camera stream and s6-svscan](./images/processes.webp)

### Stop what is running too hard

| You do | What happens |
|---|---|
| Press **Restart**, **Stop** or **Start** on an app | It asks first and says what it costs: which integrations go unavailable, and whether the app starts again at boot. |
| Press **End** on a process inside an app | The process is asked to stop. **Force end** is offered only if it is still running five seconds later. |
| Add a name to **Never end these** | **End** is never offered for that process or app. |

![The question before stopping Mosquitto broker: it stays stopped until you start it again or Home Assistant restarts, Home Assistant integrations that talk to it (mqtt) show as unavailable while it is down, and its watchdog does not restart an app you stopped yourself. Cancel and Stop buttons](./images/stop-dialog.webp)

### Catch a runaway app

| You set up | What happens |
|---|---|
| Nothing | An app above 80% CPU for 10 minutes is marked on the panel, and the **Runaway app** binary sensor turns on. |
| An automation on **Runaway app** | It restarts that app with `hassio.addon_restart` and tells you which one. [Copy the YAML](/bruh-task-manager/guide/#restart-a-runaway-app). |
| The **CPU**, **Memory used** and **Busiest app** sensors on a dashboard | The machine's load sits beside the rest of your house. |

## Two levels, three switches

| | What it shows or does | How you turn it on |
|---|---|---|
| **Level 1** | Every app, as the Supervisor measures it | On from install. Nothing to set. |
| **Level 2** | Every process on the machine | **Show every process**, then Protection mode off on this app's Info page, then a restart. |
| **End process** | **End** on processes inside apps | **Allow ending processes**. Needs Level 2. Off by default. |

## What it never does

- **Stop anything by itself.** A runaway app is marked and reported. What happens next is up to you or your automation.
- **Offer End** for Home Assistant, the Supervisor, its plugins, the operating system, the kernel, itself, an app's process supervisor, or a container it can't name.
- **Stop Home Assistant or the Supervisor.** They can be restarted, not stopped. It never offers to stop itself.
- **Read other apps' passwords or tokens.** Its AppArmor profile blocks reading another process's environment and memory, with Level 2 on or off.
- **Open a network port.**

## What you need

| | |
|---|---|
| **Home Assistant** | Home Assistant OS or Supervised, 2023.6 or newer |
| **Machine** | 64-bit: `amd64` or `aarch64` |
| **For Level 2** | Protection mode off on this one app while you look |

<Aside type="note" title="Security rating 5">
The app store rates this app 5, not 6, because it asks for the machine's process list. The
rating is the same with Protection mode on or off. brAIn's security check does not flag Task
Manager's Protection mode as a fault.
</Aside>
