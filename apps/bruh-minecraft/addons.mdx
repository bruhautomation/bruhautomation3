The **Add-ons** tab adds plugins, data packs, server mods and resource packs to the active world
from Modrinth. Everything runs on the server, so every player gets it, with nothing to install on
an iPad or console.

![The Add-ons tab: a Restart the server to finish banner naming Simple Voice Chat with Restart now; Plugins (EssentialsX, Simple Voice Chat, LuckPerms) each marked Working or Starts after a restart; a Terralith data pack; a Faithful 32x resource pack marked Not used with Use in this world; and Server software listing Paper, Geyser, Floodgate and ViaVersion with Update everything now](./images/panel-addons.webp)

## Add something

<Steps>

1. **Search.** Type what you want, such as *sit*, *vein miner* or *textures*. One search covers
   every kind. Narrow it with the chips. Only what **this** server can run is offered: the
   server type and Minecraft version decide.
2. **Add.** Press **Add to world** on a card. To add several, press **Select** on each card,
   across searches and kinds, then **Add all to world** in the tray. The limit is 25 at once.
3. **Restart** if the banner asks. Data packs work immediately.

</Steps>

![Add more: a Search Modrinth box with Search, chips for Everything, Plugins, Data packs and Resource packs, and result cards for Chunky, WorldEdit, EssentialsX (In this world, Working), Terralith, Incendium and Faithful 32x, each with Add to world and Select, and More results](./images/panel-addons-search.webp)

Anything an add-on requires is installed with it and recorded as a dependency.

**Add your own file or link** takes a plugin URL or a resource-pack `.zip` up to 250 MB. The app
serves the pack to players on your network.

## What each kind gives Bedrock players

| Kind | Runs on | What Bedrock players get |
| --- | --- | --- |
| **Plugins** | Paper, Purpur, Folia | Everything. They run on the server |
| **Data packs** | Any server type | Everything. They run in the world |
| **Server mods** | Fabric, Forge | Only mods Modrinth marks as needing nothing on the client are offered |
| **Resource packs** | Any | Java players are offered the pack on join. Geyser pushes Bedrock players a converted copy. Flat block and item textures convert. Custom 3D models and sounds do not |

A Realms add-on is a Bedrock behavior pack, which no Java server can run. Server-side add-ons are
the equivalent that reaches every device.

## See what is in the world

The top of the tab lists every plugin, data pack, server mod and resource pack the world has,
grouped by kind. That includes ones added by hand, by link or by the `plugins:` option.
A plugin added outside the browser shows the name and version it declares itself.

| Status | Meaning |
| --- | --- |
| **Working** | Loaded now |
| **Starts after a restart** | Added since the server started. Plugins, mods and a resource-pack change need a restart. Data packs reload live |
| **Turns on when the server starts** | The server is stopped |
| **Not used** | A resource pack in the library that this world does not offer. **Use in this world** switches to it |

When a restart is waiting, a banner says what changed (*Added VeinMiner, removed Chairs*) with
**Restart now**. The list refreshes until everything reads **Working**.

## Update or remove an add-on

- **Update.** Each add-on says **Up to date** or **Update to X available**. **Update** shows only
  when there is one.
- **Remove.** Removing something another add-on needs asks first. Add-ons put on the server by
  hand can be removed too, wherever the panel can remove them.
- **Conflicts.** WorldEdit and FastAsyncWorldEdit installed together are both marked, with which
  one to remove. Nothing is removed for you.

## Update the server software

**Server software** lists the server (Paper, Purpur and so on) with its Minecraft version and
build, and the cross-play plugins Geyser, Floodgate, ViaVersion and ViaBackwards.

| Press | What happens |
| --- | --- |
| **Check for updates** | Looks for newer builds now |
| **Update everything now** | Restarts the app to fetch the newest cross-play plugins. Players are disconnected for about a minute. This also happens at every start |
| **Upgrade this world** | Shown when a newer Minecraft version is out. Takes a backup, then moves the world to it |

<Aside type="caution" title="A world upgrade cannot be undone">
The upgrade rewrites the world, and a plugin built only for the old version may stop loading.
A world is never moved to a new Minecraft version unless you press **Upgrade this world**.
</Aside>

## Tick a popular plugin instead

Twelve popular plugins have a tick box on the app's **Configuration** tab. A ticked plugin is
fetched from Modrinth at every start, for your server's Minecraft version (Paper, Purpur and
Folia).

| On by default | Off until you tick them |
| --- | --- |
| ViaVersion, ViaBackwards (clients a version ahead or behind can join) | EssentialsX, EssentialsXChat, LuckPerms, WorldEdit, CoreProtect, GriefPrevention, mcMMO, ChestSort, VeinMiner, Spark |

Unticking does **not** remove the jar. Remove it on the Add-ons tab. The option names are in the
[Reference](/bruh-minecraft/reference/#plugins), and the
[Command Generator](/bruh-minecraft/command-generator/) builds commands for these plugins.

## Add add-ons from Home Assistant or brAIn

Ask [brAIn](/brain/): *"add a sit-anywhere plugin to the family world"*. The answer says whether
a restart is needed. Installing and removing need a **Whole house** or **Full admin** agent, not
a voice-level one.

| Service | Fields | What it does |
| --- | --- | --- |
| `bruh_minecraft.list_addons` | none | What the browser can offer and what the world has |
| `bruh_minecraft.search_addons` | `query`, `kind`, `offset` | Search Modrinth |
| `bruh_minecraft.install_addon` | `id`, `kind` | Add a project and what it requires |
| `bruh_minecraft.remove_addon` | `id` | Remove one |

## Safety

- Downloads come only from Modrinth's CDN and must match the SHA-512 hash Modrinth published, or
  they are refused.
- Add-ons are per world, recorded in `.bruh-addons.json` in the world folder.
