# Cellcube Stand

Advanced laboratory cell culture platform for bioreactor and sample processing. Includes Nextion HMI interface for real-time monitoring and pump control.

## Hardware
- Motor control system
- Nextion touchscreen interface
- Peristaltic pump control
- Sample circulation system
- Cole-Parmer Masterflex pump integration

## Files

### Firmware
- `firmware/` — Control firmware

### Nextion HMI
- `nextion-hmi/cc_stand_nextion_display_footswitch_float_2_5inch.HMI` — Latest (2.5-inch display, floating mode)
- `nextion-hmi/cc_stand_nextion_display_footswitch_2_5_inch.HMI` — Alternative (standard)
- `nextion-hmi/nextion_10inch_dev_2.HMI` — Large screen development version
- `nextion-hmi/old-versions/` — Previous HMI iterations

### Laser Cut Files
- `laser-cut/` — DXF files for acrylic panel cutting
- `laser-cut/cell_cube_end_cap.dxf` — End cap for structure
- `laser-cut/fludics panel_cut_sides_with_fans.dxf` — Fan-equipped side panels

### 3D Models
- `*.stl` — Printed components and adapters
