# Pump Controller Housing

Laser-cut enclosure for peristaltic pump and motor controller with Arduino electronics.

## Hardware
- Arduino microcontroller
- Motor driver circuits
- Pump control relays
- Acrylic/wood enclosure

## Files

### Laser Cut Files
- `laser-cut/Pump Controller Housing V4.dxf` — Latest design (V4)
- `laser-cut/Pump Controller Housing V4.svg` — Vector export
- `laser-cut/Front Final.dxf` — Front panel (V2)
- `laser-cut/Sides.dxf` — Side panels
- `laser-cut/Swirl Final.dxf` — Decorative swirl design

### Firmware
- `firmware/BRUHpumpcontrollerV6/` — Latest Arduino sketch (V6)

### Legacy Code
- `firmware/old-versions/` — Previous firmware versions (V1-V5)
