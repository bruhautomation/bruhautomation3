# Cellcube Bioreactor Controller

Motorised cell-culture platform with a Nextion HMI and pump control.

**Build guide:** [bruhautomation.com/projects/cellcube-bioreactor-controller](https://bruhautomation.com/projects/cellcube-bioreactor-controller/)

## What's in this folder

- `models/` — print-ready STL files (these are what the site previews)
- `laser-cut/` — DXF and SVG cut files
- `nextion-hmi/` — Nextion display projects

## Hardware
- Motor control system
- Nextion touchscreen interface
- Peristaltic pump control
- Sample circulation system
- Cole-Parmer Masterflex pump integration
