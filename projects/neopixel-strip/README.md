# Neopixel Strip

Addressable RGB LED strip with effects and OTA updates.

## What's in this folder

- `esphome/` — ESPHome configuration
- `arduino-legacy/` — pre-ESPHome Arduino sketches, kept for reference

## Hardware
- ESP8266/ESP32 microcontroller
- WS2812B (Neopixel) addressable LED strip
- WiFi/MQTT connectivity
