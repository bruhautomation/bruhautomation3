# Shelly Case

A printed two-part shell for a Shelly relay module, for the installs where there
is no wall box to hide it in — a pump, a garage opener, a fixture in a ceiling
void, an appliance behind a cabinet.

Plastic rather than a steel handy box, so it doesn't sit between the module's
PCB antenna and the access point. Print it in PETG and vent it: a metering
module and a relay both make heat, and PLA creeps.

Not a listed electrical enclosure. Where code wants mains splices in an approved
box, put an approved box there and use this inside or downstream of it.

## Hardware
- 3D-printed case, two halves, M3 heat-set inserts in the bottom
- Shelly relay module — Plus 1 PM, 1 PM, 2.5, Dimmer 0/1-10 V PM Gen3 or EM Gen3
- M3 countersunk screws to close the lid
- Zip tie for strain relief on the cable
- #8 × 1/2 in self-tappers, wall anchors or VHB tape to mount it

Measure the module you own before you print. Gen1, Plus and Gen3 outlines
differ, and the EM's CT clamp lead needs a way out of the case.
