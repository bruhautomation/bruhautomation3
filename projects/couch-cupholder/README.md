# Couch Cupholder

Arm-mounted cupholder with swappable inserts.

**Build guide:** [bruhautomation.com/projects/couch-cupholder](https://bruhautomation.com/projects/couch-cupholder/)

## What's in this folder

- `models/` — print-ready STL files (these are what the site previews)
- `cad/` — Fusion 360 sources (`.f3d`) and STEP exports

## Hardware
- 3D-printed plastic components
- Mounting hardware
