# Smart Blinds

Servo-driven motorised blinds controller.

## What's in this folder

- `models/` — print-ready STL files (these are what the site previews)
- `esphome/` — ESPHome configuration
- `arduino-legacy/` — pre-ESPHome Arduino sketches, kept for reference
- `fritzing/` — wiring diagrams

## Hardware
- ESP8266 microcontroller
- Motor driver
- DC motor for blind control
- WiFi/MQTT connectivity
