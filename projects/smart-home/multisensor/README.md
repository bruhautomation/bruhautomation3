# Multisensor

Multi-sensor node for home automation (temperature, humidity, motion, light).

## Hardware
- ESP8266/ESP32 microcontroller
- DHT temperature/humidity sensor
- Motion sensor (PIR)
- Light sensor
- WiFi/MQTT connectivity

## Files

### Firmware
- `firmware/BRUHpumpcontrollerV6/` — Arduino sketch

### Legacy Code
- `arduino-legacy/BRUHV7_sensor_node/` — Original Arduino MQTT firmware (V7)
- `arduino-legacy/bruh_mqtt_multisensor_github/` — GitHub canonical version
