# Smart Blinds

WiFi-controlled motorized blinds with MQTT integration for smart home automation.

## Hardware
- ESP8266 microcontroller
- Motor driver
- DC motor for blind control
- WiFi/MQTT connectivity

## Files

### Firmware
- `arduino-legacy/BRUHBlindsV4/` — Latest Arduino firmware (V4)
