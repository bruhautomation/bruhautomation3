# Peltier Bottle Warmer

A baby bottle warmer built around a Peltier module instead of a heating element:
a TEC1-12712 clamped between a low-profile CPU cooler and the plate a copper mug
stands on, driven through an H-bridge so the same hardware can chill a bottle as
well as warm one. A K-type thermocouple bolted to the plate closes the loop, so
it holds a temperature rather than running on a timer.

Bench prototype. The parts are all identified and the electronics are documented
on the project page; the printed base and the firmware are not in this folder
yet.
