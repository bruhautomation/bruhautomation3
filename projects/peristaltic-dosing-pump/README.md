# Peristaltic Dosing Pump

Laser-cut enclosure and Arduino firmware for peristaltic dosing pumps.

**Build guide:** [bruhautomation.com/projects/peristaltic-dosing-pump](https://bruhautomation.com/projects/peristaltic-dosing-pump/)

## What's in this folder

- `firmware/` — microcontroller firmware
- `laser-cut/` — DXF and SVG cut files

## Hardware
- Arduino microcontroller
- Motor driver circuits
- Pump control relays
- Acrylic/wood enclosure
