# DeWalt Screwdriver Holder

Holder for the DeWalt GYRO screwdriver and its bits.

## What's in this folder

- `cad/` — Fusion 360 sources (`.f3d`) and STEP exports
- `preview/` — preview meshes tessellated from the CAD (generated; the site's 3D viewer loads these)

## Hardware
- 3D-printed mounting bracket
- DeWalt GYRO screwdriver
