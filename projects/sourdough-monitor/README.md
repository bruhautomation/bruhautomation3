# Sourdough Monitor

Fermentation-tracking smart jar for sourdough starter.

## What's in this folder

- `cad/` — Fusion 360 sources (`.f3d`) and STEP exports
- `esphome/` — ESPHome configuration

## Hardware
- Temperature/humidity sensor
- WiFi connectivity
- Smart jar lid
