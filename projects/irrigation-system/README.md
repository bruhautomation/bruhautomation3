# Irrigation System

1500ft of automated irrigation with flow, pressure and TDS sensing.

**Build guide:** [bruhautomation.com/projects/irrigation-system](https://bruhautomation.com/projects/irrigation-system/)

## What's in this folder

- `cad/` — Fusion 360 sources (`.f3d`) and STEP exports
- `esphome/` — ESPHome configuration

## Hardware
- Soil moisture sensors
- Water pump/solenoid valve
- ESP32 controller
