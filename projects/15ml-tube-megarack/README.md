# 15mL Tube Megarack

High-capacity, one-piece printed storage rack for 15 mL conical centrifuge
tubes. Holds a whole run in one block instead of spreading it across several
small racks.

**Build guide:** [bruhautomation.com/projects/15ml-tube-megarack](https://bruhautomation.com/projects/15ml-tube-megarack/)

## Hardware
- One printed rack body — no fasteners, no assembly
- PETG recommended; PLA+ if the rack never sits anywhere warm
- Four self-adhesive rubber bumpers as feet
- Fits standard 15 mL conicals (about 17 mm barrel, about 120 mm long), which
  hang by the cap

Not autoclavable — 121 °C is well past soft for both PETG and PLA. Wipe down
with 70% ethanol instead.
