# Cedex Tube Rack

A printed bench rack that stages sample tubes beside the Cedex Bio HT — upright,
in run order, so a timecourse gets loaded in the order it was sampled.

**Build guide:** [bruhautomation.com/projects/cedex-tube-rack](https://bruhautomation.com/projects/cedex-tube-rack/)

## Hardware
- PETG (holds shape warm, stays tough cold, takes an ethanol wipe). PLA+ works
  on a climate-controlled bench and nowhere else.
- Four self-adhesive rubber bumpers under the base.
- Laminated label tape for the position numbers.

Measure a **capped, labelled** tube before printing — labels add a few tenths of
a millimetre, and FDM holes come out undersize. Print a two-well coupon first.

Nothing here is autoclavable. Wipe it down; don't sterilise it.
