# Childproof Doorknob

Childproof cover for Schlage Bowery knobs that still looks like the knob.

**Build guide:** [bruhautomation.com/projects/childproof-doorknob](https://bruhautomation.com/projects/childproof-doorknob/)

## What's in this folder

- `models/` — print-ready STL files (these are what the site previews)
- `cad/` — Fusion 360 sources (`.f3d`) and STEP exports
- `images/` — photos and diagrams

## Hardware
- 3D-printed plastic components
