# BRUH Playhouse

Connected outdoor playhouse with servos, lighting and audio.

**Build guide:** [bruhautomation.com/projects/playhouse](https://bruhautomation.com/projects/playhouse/)

## What's in this folder

- `cad/` — Fusion 360 sources (`.f3d`) and STEP exports
- `esphome/` — ESPHome configuration

## Hardware
- Servo motor (MG995)
- 3D-printed mechanism
